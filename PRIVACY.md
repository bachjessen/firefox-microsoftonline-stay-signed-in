# Privacy Policy

Stay Signed In, Actually does not collect, transmit, sell, or share personal information.

## Local operation

The extension runs only on `https://login.microsoftonline.com/*` to detect and handle the “Stay signed in?” prompt according to the user's preferences.

The extension stores only the following information in local browser extension storage:

- whether automation is enabled;
- the preferred Yes or No response;
- whether “Don't show this again” should be selected; and
- the number of prompts handled.

This information remains on the user's device. The extension does not use browser synchronization, analytics, telemetry, advertising, tracking, remote code, or external services.

The extension does not collect or transmit account credentials, email addresses, authentication information, browsing history, or page content.

## Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
